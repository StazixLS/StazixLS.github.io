{% comment %} Favicon: GitHub avatar site-wide, shown as a circle. On a project page, page.favicon overrides it if set and valid (checked against site.static_files), shown as a rounded square — falls back to the avatar (also rounded-square) when unset/invalid, so a project tab is always visually distinct from the main site. The 404 page gets its own fixed icon instead. Browsers don't let CSS touch the native tab icon, so the shape is baked into real pixels at runtime via ; if that fails (e.g. a cross-origin image without permissive CORS), it quietly keeps the plain, unshaped icon set below instead of breaking. {% endcomment %} {% assign icon_url = site.avatar %} {% assign icon_shape = "circle" %} {% if page.layout == "project" %} {% assign icon_shape = "rounded" %} {% assign favicon_valid = false %} {% if page.favicon and page.favicon != "" %} {% for f in site.static_files %} {% if f.path == page.favicon %} {% assign favicon_valid = true %} {% endif %} {% endfor %} {% endif %} {% if favicon_valid %} {% assign icon_url = page.favicon | absolute_url %} {% endif %} {% endif %} {% if page.url == "/404.html" %} {% assign icon_url = "/assets/missing-texture.png" | absolute_url %} {% assign icon_shape = "none" %} {% endif %} {% if icon_url and icon_url != "" %} {% if icon_shape != "none" %} {% endif %} {% endif %}
